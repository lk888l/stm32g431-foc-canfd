# 架构、时序与异常策略

`Application/include/roller` 为可在主机测试的控制、状态机、队列和器件协议；`Platform/STM32` 管理硬件；`Protocol/CANopen` 是单任务协议 actor。HAL/FreeRTOS 不进入域模型。所有任务、邮箱、协议对象和 DMA 缓冲区静态分配，最终 ELF 检查禁止分配器。

## 20 kHz 路径

1. TIM1 下溢（NVIC 2）记录已锁存的 A/B/C 占空比，消费最新完整命令，启动 SPI3 SSI DMA。
2. SPI3 三字节事务约 4.8 µs 完成；RX DMA 中断验证 CRC 并保存角度，错误只记录计数。
3. CH4 在 24.5 µs 触发 ADC1/2 同步规则组，三 rank 约在 27.275 µs 完成。DMA1 Channel1 半满/全满中断复制完整帧。
4. 根据真实低侧窗口确定哪些电流有效；三相处理、缺相重建、RL 电流预测、角度预测、dq PI 和 SVPWM 在同一中断执行。
5. 距离下溢不足提交余量时保留上一整组 PWM；满足条件时原子写 CCR 预装载，在下个自然下溢生效。首次使能也等这次锁存，避免使用上一会话的旧占空比。

ADC、SSI、TIM1 均为 NVIC 2，不互相抢占，不调用 RTOS。FDCAN IRQ 为 6，仅取至多三个硬件帧到 SPSC；CANopen 任务为 RTOS 3 / 1 ms；Supervisor 为 RTOS 2 / 10 ms。HAL 使用 TIM6，FreeRTOS 独占 SysTick/SVC/PendSV。

| DMA1 通道 | 用途 |
|---|---|
| 1 | ADC1/ADC2 公共 CDR，32 位循环双帧 |
| 2 / 3 | SPI3 RX / TX，三个 8 位字节 |
| 4 / 5 / 6 | 已释放；PWM 和 CORDIC 短事务直接访问寄存器 |

CORDIC 六次迭代周期，两个 Q31 输入/输出；不再建立短 DMA 并同步轮询。初始化比较 257 个角度；运行时异常回退软件 sin/cos。DWT 记录控制路径和 SSI 最坏周期数；只读 Bringup 的耗时不能当作带载电流环 WCET。

## 保持输出与诊断

| 条件 | 行为 |
|---|---|
| 单帧 CRC、异常角度或 SSI 超时 | 丢弃该帧，以上一有效角度/速度预测，记录编码器错误 |
| 低侧窗口不足、ADC overrun | 使用有效相重建/电流预测，记录计数 |
| 单次 PWM 提交太晚 | 保留三相旧占空比，下一周期再提交 |
| 100 ms 无新目标、心跳超时、bus-off、CAN 队列溢出 | 网络告警，保持最后完整运动目标；bus-off 尝试恢复 |
| PDO 含非法值 | 回退该批 OD 更新、保持最后完整命令；SDO 返回错误码 |
| 超出跟随误差窗口、软件电压/温度/电流阈值 | 设置 warning，不因这些阈值直接关桥 |
| 收到明确 Disable / NMT Stop / Pre-operational | 按显式命令停止输出 |
| 校准跟随验证失败 | 终止这次显式校准，不保存错误偏置 |
| 初始化配置不可用、真实 driver fault（接口预留）、CPU 异常 | 故障处理；此板未接 nFAULT |
| 控制或 CAN 任务持续约 200 ms 不前进 | 保留原有 watchdog 重启机制，避免卡死后永远输出旧电压 |

`0x6041` bit7 为 warning。`roller_hardware.warnings` 位 0..7 分别为角度预测、电流预测、通信、跟随误差、电压、温度、电流、数学输入异常；`hardware_probe.py` 通过不可变快照读取。Bringup 下电流预测告警是驱动睡眠导致的预期现象，不是编码器失败。

运行异常保持目标是本项目明确策略，主站不能再将停止发送命令当作停止电机。停止应发送控制字或 NMT 停止命令。硬件自身 UVLO/OCP/过热动作无法由此策略取消。

## 协议、命令与参数

NMT 在 `receive()` 中按帧到达顺序处理状态边界。Pre-operational 的 PDO 不入缓存；状态切换清空旧 RPDO 和压缩 MIT 会话标志，防止旧数据进入新 Operational 会话。PDO 批处理前保存 OD 快照，非法字段不发布部分命令。快照位于静态 Node 对象，避免叠加到 SDO 保存调用的任务栈。

命令/遥测 SPSC 使用 release/acquire 原子索引。队列满时保留已完整提交的数据并记录诊断，不锁住输出。状态机只在 1 kHz 消费控制字边沿。速度反向先按减速度到零，用剩余时间按加速度反向建立速度。

Flash 为最后两页双页提交日志，程序区 124 KiB。保存仅在非运行、控制字 0、实际 PWM 未使能时进行，暂停采样避免单 Bank Flash 取指停顿。当前 schema v3 与新电机匹配；旧 v1/v2 只迁移可持久化通信/运动限值，丢弃旧电机角度、方向和电流限值，重新采用 4015 参数。控制字和运行目标从不恢复。
