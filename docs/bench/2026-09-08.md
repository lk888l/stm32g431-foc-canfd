# Unit-RollerCAN 实机调试，2026-09-08

供电设置 11.6 V，轴无负载。STM32G431CB、ST-Link V2，SWD 1800 kHz。探针报告约 0.58 V，但实际 MCU VREFINT 换算 VDDA 约 3.304 V，烧录、校验和运行正常。连接前的完整 128 KiB Flash 已备份到本机 `.work/lab-20260908/original-flash.bin`；原理图和原固件备份不随开源仓库分发。

使用真实电机、ADC、SPI、PWM、FreeRTOS 和 CANopenNode。命令由 SWD 邮箱注入，**物理 CAN 收发和主站互通未测试**。过压、欠压、过流、编码器、时序和命令租约保护均保持启用。

## 修正与测量

| 问题 | 修正 / 结果 |
|---|---|
| 母线分压误读 | R18 实为 12 kΩ；比例由 11 改为 71/11。原先把 11.6 V 报成约 19.86 V，现读数约 11.65 V |
| 相电流反馈反向 | 正 α 矢量下 A 相 ADC 高于零点；改为 `raw - offset`，正负 Iq 闭环跟踪通过 |
| 控制回调超时 | 原 Debug 最大 9376 cycles / 58.6 µs；最终 Bench 回归最大 6929 cycles / 43.306 µs |
| 单电周校准不可靠 | 原 0.6 V 单圈扫描曾得到 8 和 7 两种极对数；改为 1.2 V、四电周扫描、停稳后计算 |
| 电流环响应偏慢 | 电流 PI 从 0.8 / 100 调为 2 / 600；速度 PI 保留 0.06 / 0.15 |
| 保存后的调度异常 | 采样 epoch 重建进度基线，周期任务跳过过期释放点；连续 10 次保存无故障、无重启 |
| 校准取消语义 | 限定 NMT Pre-operational，NMT Stop 中止校准并关桥；控制字 0 不承担校准取消 |

性能改动包括热路径 `-O2`、完整 newlib 的内存拷贝、在 CAN 任务验证不可变命令、CRC 查表、CORDIC sin/cos、针对正常范围的角度归一化和矢量限幅。CORDIC 上电 257 点对照的最大绝对误差为 1.133×10⁻⁶；运行时运算失败关桥，同周期的故障复位不能清掉持续的运算故障。完整回调的保护阈值仍为 45 µs，观测值不是正式最坏执行时间证明。

三次多圈校准均得到 **7 极对、direction=-1**，电角偏移分别约 0.5375、0.5601、0.4888 rad，跨度约 4.1° 电角。最后一次已保存；默认配置仍要求每个新模块自行校准。偏移仍受对齐与齿槽转矩影响，不能作为精密转矩标定。

## 速度对比

以下使用相同供电、负载和已保存校准。每个目标持续约 3 s，统计后 1.5 s 的主机抽样；只比较电流 PI 调整前后。它们是调试过程中的短时试验，不代表统计性性能保证。

| 目标 rev/s | 原电流 PI：速度误差 RMS | 新电流 PI：速度误差 RMS |
|---:|---:|---:|
| +0.5 | 0.1463 | 0.0946 |
| -0.5 | 0.1564 | 0.0727 |
| +1.0 | 0.2153 | 0.1155 |
| -1.0 | 0.2282 | 0.1075 |

误差降低约 35%–53%。进一步将速度 PI 加倍会增加 ±1 rev/s 的波动，因此未采用。仍存在可见的低速齿槽波动，需要更高精度时再做负载辨识、滤波和齿槽补偿。

最终参数下另测 ±5 rev/s（±300 rpm），后 1.5 s 的均值分别为 +5.0014、−5.0016 rev/s，速度误差 RMS 分别为 0.1063、0.1193 rev/s；没有故障。该试验主机抽样中的最大相电流约 0.086 A，不能把低速遥测的峰值当作全频带瞬态峰值。

## 其他实机检查

- 位置相对初始位置 +0.25 / −0.25 / 0 rev，每点运行 2 s，最终回归的末端偏差最大约 0.00208 rev（0.75°）。
- 转矩模式命令 ±100 千分比，对应 Iq 目标 ±0.025 A，实际反馈方向正确，误差小于 0.015 A。
- 从 2 rev/s 发 quick-stop，1 s 后速度接近 0、状态 disabled、PB2 低，无自动重启。
- 停止运动写入约 180 ms 后，0x8130 通信故障、关桥。一次 Windows 停顿约 125 ms 也触发了相同保护。
- 连续 10 次 SDO `0x1010:1` 保存，采样 epoch 每次递增，采样持续前进，没有误触发停滞保护。复位恢复校准，同时保持控制字 0 和关桥。
- 校准期间 NMT Stop 使校准进入 failed、关桥；复位可恢复之前显式保存的校准。
- Bench 的 CAN / Supervisor 最小剩余栈为 478 / 227 words；短时测试 MCU 内温约 38–40°C，不代表绕组温升验收。

结束测试后已烧录并校验正常 Release 固件，程序映像 64804 B，SHA-256 为 `6da410879de4fb2ac6c4beddf8a15d1aafe77e452fc317c97b043db48b8453df`。最后 4096 B 参数页逐字节不变，校准恢复正常，ADC 计数持续前进，panic/inhibit 为 0、PB2 为低。

Release 恢复物理 CAN 后出现 ACK 错误：PSR=0x77B、TEC=128、TX FIFO 满；约 2 s 后进入 0x8130 通信故障并保持关桥。当前未建立有效 CAN 对端通信，需要接通可应答的主站后验证接线、终端、波特率及恢复流程。完整待测项目见 [验证范围](../validation.md)。
