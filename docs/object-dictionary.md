# Implemented object dictionary

Generated by `tools/generate_od.py`. Motion position and velocity use Float32 revolutions and revolutions/second. CANopen services and PDOs up to 8 bytes use classic CAN; longer PDOs use the manufacturer CAN-FD+BRS extension, up to 64 bytes and 16 mapping entries. This is not a certified CiA 402 or CiA 1301 profile. See [the protocol guide](protocol.md) for startup, calibration, control sequences and parameter persistence.

Communication defaults are 1 Mbit/s nominal, 5 Mbit/s data, BRS enabled. 0x2001:02 accepts 125000/250000/500000/1000000 bit/s; :03 accepts 1000000/2000000/4000000/5000000/8000000 bit/s. Rate writes require NMT Pre-operational, disabled/fault state, and controlword 0. They stage values only: save with 0x1010:01 = 0x65766173, then NMT Reset Communication/Node (or reboot) to apply. Unsaved changes are discarded on reset. BRS :04 is read-only 1. Version 1 settings migrate in RAM, preserving calibration and existing PDO/communication settings while using the new default rates; explicit save creates version 2.

Mode 0x6060/0x6061 is signed int8: -1 (wire 0xFF) = manufacturer single-turn shortest-path position; 0 = disabled; 1 = multi-turn profile position; 3 = profile velocity; 4 = profile torque; 5 = MIT. Both position modes use 0x607A and controlword bit4/bit6. Actual position 0x6064 always reports accumulated revolutions since boot, including in single-turn mode; turn count is not retained across power loss.
