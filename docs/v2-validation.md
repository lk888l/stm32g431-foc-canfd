本次对应 STM32G431CBU6 + DRV8316CT + MT6701 + 4015/11 极对电机。用户要求接入电机但暂不转动；全程只烧录 Bringup，未执行对齐、电角校准、开环旋转或闭环使能。

## 最终实机状态

- Bringup ELF SHA-256：`09395f5dd6504f818ac5bc888a471b355aabdf92b39ade09b34216c1d3a487af`。
- 已烧录并由 OpenOCD 报告 `Verified OK`，最后一次上电后超过 1,557,860 个控制样本。
- PB10/nSLEEP 始终低；TIM1 CH1/2/3 未使能；PA8/PA9/PA10 为输出低电平 GPIO。
- 控制器 fault=0、calibration=required，未保存新的电角校准。状态字 warning 来自睡眠中的电流测量不可用，非编码器错误。
- 原始 128 KiB Flash 备份：`.work/hardware-v2/original-flash.bin`。最后 4 KiB 参数区读取后逐字节与备份比较一致。

## 软件验证

- Debug、Release、Bringup 构建与 ELF 检查通过，未链接动态分配器。
- 两个 CTest：域/协议与 CAN-FD，通过。
- Python 工具 29 项测试通过，包含显式停止失败后先暂停 MCU、再关闭驱动的回归测试。
- CRC 验证覆盖所有 262,144 个 18 位负载，以及每帧 24 个单比特翻转。
- 对完整 `24/√3` 电压圆扫描 7,200 个方向，反算实际线电压矢量，无人为 10%～90% 裁剪。
- 低侧采样孔径、PWM 提交边界、缺相重建和独立 RL 模型缺测段已覆盖。
- 回归覆盖：反向减速度、失步误识别极对数、NaN B/C 相与故障复位、Pre-op PDO 后紧接 NMT Start、旧 v1/v2 校准不复用、坏 PDO 不阻挡明确停止。

最终 Release 使用 Flash 75,768 B / 124 KiB，RAM 27,200 B / 32 KiB；Bringup 使用 Flash 80,700 B、RAM 27,408 B。
